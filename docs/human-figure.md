# 정비율 인간 캐릭터 — 뼈대에서 제품급까지

> `apps/human/`의 방랑자(`human.char.wanderer`, `scripts/human.py`)가 어떻게 만들어졌는지.
> [character-rig-guide.md](character-rig-guide.md)의 순서(시점 → 크기 → 뼈대 → 자세 → 덩어리 →
> 깊이 → 파트 → 동작 → 검사)를 32px 치비 로스터가 아니라 **7.5등신 인체**에 적용한 기록이고,
> 다음 인간 캐릭터는 이 숫자를 복사해 바꾸면 된다.

## 0. 왜 새 앱인가

`ss`의 로스터는 32×32에 머리가 키의 1/3이다. 정비율 인체는 머리가 키의 2/15이고, 팔다리가 각각
두 마디씩 보여야 걷기가 읽힌다. 캔버스·크기 규칙·바닥이 다르므로 네임스페이스를 따로 뒀다:
`apps/human/app.json`은 캐릭터 캔버스를 192×192로, 필수 클립을 `idle walk run attack hurt
death`로, `death`는 0.85에 멈추는 원샷으로 정한다. 바닥은 `human.env.floor`(어두운 돌), 게임 배율 1×.

## 1. 자

머리 하나 = **H = 16px**. 키 7.5H = 120px. 원점은 **골반(엉덩이 관절)**, +y 아래. 바닥(발바닥 선)은 +60.

| 지점 | y | H |
| --- | --- | --- |
| 정수리 | −60 | 0 |
| 턱 | −44 | 1 |
| 어깨 라인 | −37 | 1.4 |
| 젖꼭지 라인 | −28 | 2 |
| 허리(가장 가는 곳) | −17 | 2.7 |
| 골반 / 원점 | 0 | 3.75 |
| 무릎 | +28 | 5.5 |
| 발목 | +54 | 7.1 |
| 발바닥 | +60 | 7.5 |

길이: 허벅지 28 · 정강이 26 · 발 높이 6 · 위팔 21 · 아래팔 19 · 손 9. 팔을 늘어뜨리면 손끝이 허벅지
중간(+13)에 온다 — 정비율의 검사점이다. 어깨 폭은 정면에서 2H이고, 3/4 시점에서 화면상 어깨 라인은
가까운 어깨 (−5, −35.5) → 먼 어깨 (+4.6, −37.5): 11px, 먼 쪽이 2px 높다.

## 2. 시점

**오른쪽(+x)을 보는 3/4 측면.** Dead Cells·Hades가 쓰는 시점이다. 몸통은 카메라 쪽으로 25°쯤
돌아 있고 다리는 거의 옆에서 본다 — 걷기가 x축에서 가위질하도록. 그래서:

- 가까운(오른) 어깨가 화면상 살짝 **뒤·아래**, 먼(왼) 어깨가 **앞·위**
- 먼 팔은 가슴 윤곽 안쪽에 매달려 가슴 **아래**에 그려지고, 허리 옆과 엉덩이 옆으로 1~2px만 비친다
- 먼 팔다리는 한 단계 어둡고(`.dark`), 먼 발은 1px 높이 선다
- 왼쪽으로 갈 때는 엔진이 프레임을 거울상으로 뒤집는다

## 3. 뼈대 (`scripts/rig.py` 위에)

```
pelvis (root, 0,0)
├─ spine  (0,−3)  −86°  15     허리 — 올라가며 살짝 앞으로
│  └─ chest      −93°  19      가슴 — 살짝 뒤로: 얕은 S자
│     ├─ neck    −78°   7
│     │  └─ head −84°   8      끝이 두개골 중심
│     ├─ arm_n_upper (−5,−35.5)  97° 21 → arm_n_fore 82° 19 → hand_n 80° 9
│     ├─ arm_f_upper (4.6,−37.5) 92° 21 → arm_f_fore 79° 19 → hand_f 77° 9
│     └─ cape_0 (−7.5,−36.5) 92° 24 → cape_1 95° 22 → cape_2 98° 20
├─ leg_n_thigh (−2, 0.5) → leg_n_shin → foot_n 0° 12      IK, 무릎 앞으로
└─ leg_f_thigh (2,−0.5)  → leg_f_shin → foot_f
```

- 다리는 매 프레임 `ik2(hip, ankle, 28, 26, +1)`로 **발목을 땅에 심는다**. 몸이 내려가면 무릎이 접히고,
  발이 땅에 있는 동안은 몸이 그 위를 지나간다. `plant(pose, ankles, pitch)`가 한 번에 푼다.
- 팔은 상대 각(`arm_n_upper: dθ`)으로 흔들고, 전투 클립은 절대 헤딩(`abs:`)으로 자세를 적는다 —
  "날이 어깨 위에서 앞을 향한다"는 각도 셋(위팔·아래팔·손)이지 오프셋이 아니다.
- 망토는 가슴에 매달린 3마디 체인. 몸이 하는 일을 한 박자 늦게 따라간다(`cape(pose, trail, sway, t)`).
- 파트는 전부 `on_bone(bone, along, across)`로 뼈 위에 놓인다. along은 뼈를 따라, across는 뼈의
  오른손 쪽 — 아래를 향한 뼈에서는 **뒤쪽**이다. 그래서 각 사지 다각형은 앞 가장자리를 먼저, 뒷
  가장자리를 나중에 나열하고, `band(pts, i0, i1, w, side)`가 그 가장자리를 따라 그림자/빛 띠를 만든다.

## 4. 값과 빛

빛은 저장소 규칙대로 **왼쪽 위**. 오른쪽을 보는 몸이니 등과 정수리가 밝고 앞면·아랫면이 그늘이다.
재질마다 토큰 하나와 램프: `$skin $trouser $leather $tunic $cloak` + `.light/.dark/.dark2`, 금속은
`$steel`(base)과 `$brass`, 악센트는 후드 안감의 `$crimson` 하나.

- 모든 덩어리: 앞 가장자리에 그림자 띠(`.dark`), 큰 덩어리는 뒷 가장자리에 빛 띠(`.light`)
- 먼 쪽: 본체 `.dark`, 그림자 `.dark2`, 빛 없음
- 실루엣 파트(몸통·머리·망토·후드)는 `thin` 잉크, 안쪽 파트(사지·손·끈)는 `hair`
- 얼굴은 후드 그늘 안(`$ink@0.4`)에 있고 눈에 흰 점 하나

## 7. 다음 캐릭터를 만들 때

1. `scripts/human.py`를 복사하고 §1의 자와 §3의 뼈대 표만 바꾼다. 여자는 어깨 라인 1.5H·골반 넓게,
   아이는 H를 키우고(머리 비율) 사지를 줄인다.
2. 의상은 `clothes(...)`로 감싸 넣는다 — `bare` 변형이 자동으로 벗긴다.
3. 클립은 자세 함수로 쓴다. 원샷은 `smooth()`로 예비, `snap()`으로 릴리스, 마지막 15%는 정지.
4. `sheet.ts`(경계), `filmstrip.ts`(프레임), `motion.ts`(움직임 크기), `readability.ts`(대비)를 돌리고
   `npm run baseline -- --app human`으로 받아들인다.
